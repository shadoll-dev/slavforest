# Slav Forest

**https://www.slavforest.com.ua/**

Corporate website for **Slav Forest** — a Ukrainian timber products company since 2016.

## Pages

| Page | UA | EN |
|------|----|----|
| Main | `index.html` | `index_en.html` |
| Reports & Documents | `reports.html` | `reports_en.html` |

## Tech Stack

- Static HTML/CSS/JS — no build step
- Bootstrap 3.1.1
- jQuery 1.11.3
- PDF.js 3.11 — client-side PDF thumbnail rendering
- WOW.js + Animate.css — scroll animations
